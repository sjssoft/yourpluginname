# WordPress Plugin Boilerplate (`yourpluginname`)

A clean, modern, and lightweight **WordPress plugin starter boilerplate** designed for beginners, computer science students, and developers building custom WordPress plugins from scratch without unnecessary bloat.

Unlike heavy enterprise generators, this starter kit demonstrates core **WordPress Plugin API** architecture in clear, readable PHP and Vanilla JavaScript—covering Custom Post Types, Shortcodes, the WordPress Settings API, secure AJAX handlers, and proper script/style enqueuing.
